# M1 golden session

This directory is the compact, reviewable reference session for the no-hardware
`PRESS_BUTTON` slice. The records are generated by the real Python domain services with a
fixed clock and UUID stream, then replayed and compared byte-for-byte by the release gate.

`messages.jsonl` is an ordered delivery log. `TRANSPORT_RETRANSMISSION` repeats the same
immutable envelope and `SEMANTIC_DUPLICATE` uses a new envelope identity for the same
contract. Both must converge on one durable dummy effect.

The strict `expected-mission-view.json` is the presentation-neutral `dtt/0` frame consumed
by Unreal. It keeps measured confirmation, predicted arrival and the operator-asserted target
separate. No record enables a physical or simulated actuator path.

Arrival carries a `PredictionManifest`. The target deliberately carries an operator-assertion
manifest and condition instead of being mislabeled as a prediction; both are recorded under
`projection_manifests` in `expected-domain-state.json`.

Regenerate and verify from the repository root:

```text
python -m deferred_teleop.release_gate generate
python -m deferred_teleop.release_gate verify --scope ci --skip-pytest
```

Run the complete automated matrix and the final release decision with:

```text
python -m deferred_teleop.release_gate verify --scope release
```

The release command intentionally remains non-zero while a mandatory manual/platform item
in `release/m1/release-checklist.json` is not `PASSED`.
